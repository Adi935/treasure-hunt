# Hunt Decoder

Decoder page for the campus treasure hunt. Teams paste the text from a clue card's QR code and the puzzle appears.

## Publish on GitHub Pages

1. Create a new **public** repository (for example `hunt-decoder`).
2. Upload `index.html`, `.nojekyll` and this `README.md` to the root of the `main` branch.
3. Go to **Settings > Pages**. Under "Build and deployment", set Source to **Deploy from a branch**, branch **main**, folder **/ (root)**, and save.
4. Wait a minute or two. The site appears at `https://<your-username>.github.io/hunt-decoder/`.

## Notes

- Only upload these files. Never put the HQ answer key or the card PDF in this repository: it is public.
- The page needs the `https://` address to work.
- Once loaded, decoding works offline.
